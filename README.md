# CodingAgentIM

给 AI Coding Agent 一个钉钉号。你发消息，它写代码。

## 这是什么

你在钉钉发一条消息 →  AI Agent 在你的项目里执行开发任务 → 结果回复到钉钉。

就像给你的 AI 程序员配了一个钉钉工位。它随时在线，秒级响应。

## 它怎么工作

```
你（钉钉）──「快排」──▶ Agent ──写代码──▶ 结果回复给你
```

完整流程：

1. 你在钉钉发消息（比如「写个快排」「有什么优化计划」）
2. 1 秒内收到确认「👌 收到，Coding Agent 处理中」
3. Agent 在你的项目目录里真正执行（写代码、跑测试、查资料）
4. 完成后把结果发回你的钉钉

## 你能让它做什么

- 💻 写代码、实现功能
- 🔍 排查 bug、分析问题
- 📊 分析项目状态、给优化建议
- 🧪 跑测试、检查代码质量
- ❓ 回答技术问题

## 控制它的话多话少

在钉钉直接发：

| 发送 | 效果 |
|------|------|
| `话痨` | 过程中发中间进展 |
| `正常` | 收到确认 + 最终结果 |
| `静默` | 只发最终结果 |

## 安装（一条命令）

```bash
pip install codingagentim
codingagentim init
```

按提示配好钉钉 key 就行。之后开机自启，不用管。
